# 🛡️ Baseera | بصيرة — Drug Crisis Data Analysis & Interactive Web Report

**Baseera (بصيرة)** is a data-analysis and public-awareness project that transforms findings from accidental drug-related death data into an interactive bilingual web report instead of a traditional static report.

The project is presented across two repositories: the **data-science analysis** and this **interactive web experience**.

## 🎯 Project Story

The workflow behind Baseera follows a simple idea:

**Raw Data → Data Analysis → Machine Learning → Insights → Visualization → Interactive Web Report**

The analysis repository contains a dataset of **9,200+ accidental drug-related death records** and a Jupyter Notebook used to investigate temporal trends, demographic patterns, and substance-related risk. The findings are then communicated here through a responsive Arabic/English website.

## 📊 Data & Analytical Insights

The analysis highlighted several patterns that shaped the report:
- Fentanyl appeared in more than **5,670 cases** in the analyzed data.
- Approximately **74.2%** of recorded victims were male.
- Recorded deaths increased from **355 in 2012** to more than **1,500 in 2021**.
- The analysis also explored classification-oriented modeling, imbalance handling, and feature engineering.

## 🧠 Data Science Workflow

The companion analysis includes:
- Data cleaning and exploratory analysis
- Feature engineering
- Imbalanced-data handling with **SMOTE**
- PCA-based dimensionality reduction
- Classification experiments with **Scikit-learn / XGBoost**
- Hyperparameter tuning with **GridSearchCV**

Rather than leaving those results inside a notebook or PDF, Baseera turns the key findings into a public-facing data story.

## 🌐 Interactive Report

The website provides:
- **Arabic / English localization**
- Automatic **RTL / LTR** layout switching
- Interactive visualizations with **Chart.js**
- Scroll-triggered chart animations using the Intersection Observer API
- Responsive report-style design
- Structured awareness and emergency-information sections

## 🛠️ Tech Stack

**Data Analysis:** Python · Pandas · NumPy · Scikit-learn · XGBoost · Imbalanced-learn  
**Visualization:** Matplotlib · Seaborn · Chart.js  
**Web:** HTML5 · CSS3 · JavaScript

# 👁️ Baseera — A Vision to Save Lives

**Baseera (بصيرة)** is a bilingual Arabic/English public-awareness web experience that turns crisis statistics and safety information into an accessible, interactive visual report.

## 🎯 Project Goal
Present complex public-safety information in a clear format that helps users understand trends, key risks, and emergency-response guidance through interactive data visualizations.

## ✨ Features
- Arabic and English interface
- RTL/LTR language switching
- Interactive Chart.js visualizations
- Responsive report-style layout
- Animated charts triggered while scrolling
- Persistent language preference using localStorage
- Emergency-awareness content presented in structured sections

## 🛠️ Tech Stack
**HTML5 · CSS3 · JavaScript · Chart.js · Font Awesome · Responsive Web Design**

## 📊 Visual Storytelling
The interface uses line, bar, and doughnut charts to present historical trends, category comparisons, and emergency-awareness information in a format designed for quick understanding.

## 📂 Repository Structure
- `index.html` — main bilingual report interface
- `style_report.css` — responsive visual design
- `script_report.js` — translations, charts, animations, and interactions
- `img/` — project visual assets

## 🌐 Language Support
Baseera supports both **Arabic** and **English** and automatically switches page direction between RTL and LTR.

## ⚠️ Important Note
This repository is a **data-visualization and public-awareness web project**. Health and emergency information should be verified against authoritative medical and public-health sources before real-world use.
